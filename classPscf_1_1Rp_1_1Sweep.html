Detailed Description

template<int D, class T>
class Pscf::Rp::Sweep< D, T >

Solve a sequence of SCFT problems along a line in parameter space.

Instantiations of this class template are used as base classes for two closely analogous class templates, also named Sweep, that are defined in Rpc and Rpg namespaces and used in the pscf_rpc and pscf_rpg programs, respectively.

Template parameters:

  • D : dimension
  • T : Types class, Rpc::Types<D> or Rpg::Types<D>
