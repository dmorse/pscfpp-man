Detailed Description

template<int D>
class Pscf::Rpc::BdMove< D >

Brownian dynamics Monte-Carlo move.

Specializations of this template with D=1, 2, and 3 are derived from specializations of the base class template Rp::BdMove < D, Types<D> >, and inherit their public interface and almost all of their source code from this base class.
