Detailed Description

template<int D>
struct Pscf::Rpc::SimState< D >

SimState stores the state used by an FTS simulation.

This class is used to restore the state of FTS simulation after an attempted move or step that is rejected or fails to converge.

Specializations of this template with D=1, 2, and 3 are derived from corresponding specializations of base class template Rp::SimState, and inherit their public interface and all of their source code from this base class.
