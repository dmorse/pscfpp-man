Detailed Description

template<int D, class CFT, class FIT>
class Pscf::Cp::CFields< D, CFT, FIT >

A container of complex-valued concentration fields (c fields).

Overview : A CFields container has an array of nMonomer chemical fields (c fields) that are each associated with a monomer type. Fields can be accessed as const or non const references, or written to file.

Template parameters : The template parameters represent: 

- D   : integer dimensionality of space, D=1,2, or 3
- CFT : complex field type (e.g., CField<D>)
- FIT : FieldIo type for field io operations (e.g., FieldIo<D>)

Subclasses : Partial specializations of CFields are used as base classes for classes Cpc::CFields <D > and Rpg::CFields <D>:

  • Subclass Cpc::CFields <D> is derived from a partial specialization of CFields with template parameters CFT = Cpu::CFT <D> and FIT = Cpc::FIT <D> , and is used in the pscf_cpc CPU program.
  • Subclass Rpg::CFields <D> is derived from a partial specialization of CFields with template parameters CFT = Cuda::CFT <D> and FIT = Rpg::FIT <D> , and is used in the pscf_cpg GPU accelerated program.
