Detailed Description

template<int D>
class Pscf::Rpg::Simulator< D >

Field theoretic simulator (base class).

Specializations of this template with D=1, 2, and 3 are derived from specializations of the base class template Rp::Simulator, and inherit their entire public interface and almost all of their source code from this base class.
