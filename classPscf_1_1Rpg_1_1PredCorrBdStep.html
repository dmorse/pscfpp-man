Detailed Description

template<int D>
class Pscf::Rpg::PredCorrBdStep< D >

Predictor-corrector Brownian dynamics time stepper.

Specializations of this template with D=1, 2, and 3 are derived from specializations of the base class template Rp::PredCorrBdStep, and inherit their public interface and almost all of their source code from this base class.
