Appendix: Modified Diffusion Equations

Thin-Film Confinement (Prev)         Partial Saddle-Point Field Theoretic Simulation (PS-FTS) (Next)

Below, we describe the self-consistent field theory (SCFT) equations that are solved by PSCF, giving a complete overview of the mathematical system of equations that are solved by the software and summarizing their connection to corresponding physical properties. This is not intended to be an introduction to the field theory itself, and we do not provide a derivation of the SCFT equations. The presentation assumes some familiarity with polymer physics and statistical mechanics.

Model and notation

PSCF solves the SCFT equations for an incompressible mixture of any number of block polymer species and point-like solvent molecular species.

In what follows, we consider a system with \( C \) distinct monomer types, \( P \) block polymer species, \( S\) solvent species. We use a convention in which the symbols \( i, j = 0, \ldots, C-1\) are used as indices for monomer types, symbols \( m, n \) are used as indices for blocks within a specific block polymer species, and symbols \( a, b\) are used as indices for molecular species indices. In these notes, we use a convention in which species indices are ordered with all polymeric species listed first, so that species index values in the range \( a, b = 0, \ldots, P-1\) denote polymeric species, and values in the range \( P,\ldots, P+S-1 \) denote solvent species. A zero-based indexing scheme for indices is used throughout the notes to facilitate comparison to C/C++ source code.

To characterize inhomogeneous states, we consider the average number concentration \(\langle c_{i}({\bf r}) \rangle\) for monomers of each type \( i \) at each position \( {\bf r} \). In a model for an effectively incompressible liquid in which each monomer is assumed to occupy a volume \( v \), we may define a non-dimensional monomer concentration

\[ \phi_{i}(\textbf{r}) = v \langle c_{i}({\bf r}) \rangle \quad, \quad\quad\quad\quad\quad (1) \]

for each monomer type, where \( v \) is a monomer reference volume that. By convention, we required that \( v \) has the same value for all monomer types. The non-dimensional monomer concentration fields \( \phi_{0}, \ldots, \phi_{C-1} \) are referred to elsewhere in the PSCF documentation as "c fields".

Incompressibility is imposed at a mean-field level by requiring that

\[ 1 = \sum_{i=0}^{C-1} \phi_{i}({\bf r}) \quad\quad\quad\quad\quad (2) \]

at every position \( {\bf r} \) within the problem domain. In such an incompressible liquid, each of the non-dimensional monomer concentration fields may also be interpreted as local volume fraction for the specified monomer type. These "c fields" are thus also sometimes referred to a volume fraction fields.

Self-consistent field approximation

SCFT for a liquid of flexible polymers is based on a mean-field approximation that allows us to approximately predict properties of an interacting liquid by considering the behavior of a corresponding inhomogeneous gas of noninteracting molecules. We refer to this hypothetical non-interacting gas as the ideal-gas reference system. The ideal gas reference system must have the same chemical composition as the real system of interest and an inhomogeneous average concenration \( \langle c_{i}({\bf r}) \rangle \) for each monomer type \( i \) that is equal to that in the real system. Inhomogeneous monomer concentrations are induced in this reference system by a set of potential energy fields that couple to different types of monomer: Each monomer of type \( i \) at position \( {\bf r} \) within this ideal gas is subjected to a potential \( k_{B}Tw_{i}(\textbf{r}) \). In a self-consistent field approximation, this potential represents a free energy cost for placing a monomer of a specified type at a specified position, due to interactions among monomers within an inhomogeneous structure.

In SCFT, the monomer chemical potential fields (or "w fields") \( w_{0}, \ldots, w_{C-1} \) at each position \( {\bf r} \) are assumed to depend upon monomer volume fraction fields near that point in a manner that reflects the mixing thermodynamics of the types of monomer present in a mixture. PSCF currently uses a simple approximation for the dependence of the w fields on local composition that is based on an inhomogeneous generalization of the model for excess free energy used in the Flory-Huggins theory of homogeneous polymer mixtures. In this approximation, a solution to the SCFT problem is required to satisfy the self-consistent field (SCF) equations

\[ w_{i}({\bf r}) = \sum_{j=0}^{C-1} \chi_{ij} \phi_{j}({\bf r}) + \xi({\bf r}) \quad\quad\quad\quad\quad (3) \]

for all \( i = 0,\ldots,C-1 \), where \( \chi_{ij}\) is a dimensionless binary Flory-Huggins interaction parameter for monomer types \( i \) and \( j \), defined such that \( \chi_{ij} = \chi_{ji} \). Here, \( \xi({\bf r}) \) is a dimensionless Lagrange multiplier pressure field that must be chosen such that the monomer concentrations in the ideal gas reference system satisfy the incompressibility constraint given above.

In SCFT, average monomer concentration and volume fraction fields are computed by computing these properties for the ideal gas reference system. An iterative solution of an SCFT problem thus starts with an initial guess for the w fields for all monomer types, followed by iterative adjustment of these fields until the w fields and corresponding c fields satisfy the SCF equations and the incompressibility constraint.

Branched Polymer Topology

Each polymer species in a system modeled by PSCF must be a block polymer consisting of one or more blocks connected at junction points. Homopolymers are treated as a special case of a block polymer with only one block. Let \( B_{a} \) denote the number of blocks in block polymer species number \( a \), for \( a = 0, \ldots, P-1 \).

Each block within a block polymer connects two vertices. Each such vertex is either a junction to which two or more blocks are connected or a chain end to which only one block is attached. In the language of graph theory, every allowed polymer structure corresponds to an acyclic connected graph (also known as a "tree") with some number of "edges" (or blocks) and "nodes" (or vertices). PSCF can only handle polymers with the topology of a connected acyclic graph, in which there is exactly one path (i.e., sequence of connected edges) connecting any two vertices. A standard theorem of graph theory aserts that any connected acyclic graph with \( B_{a} \) edges must have exactly \( B_{a} + 1 \) vertices or nodes. An acyclic block polymer with \( B_{a} \) blocks thus always has exactly \( B_{a} + 1 \) vertices (i.e., junctions and free chain ends). For example, a linear triblock terpolymer with three blocks in a row has four vertices (two free ends and two junctions), and so does a star triblock copolymer with three blocks that meet at a central junction (three free ends and one junction).

PSCF assigns each block within a polymer species \( a \) an integer index in the range \( [0, \ldots, B_{a}-1 ]\), where \( B_{a} \) is the number of blocks in that species. Each of the \( B_{a} + 1 \) vertices within such a species (i.e., each junction or chain end) is assigned an integer index in the range \( [ 0, \ldots, B_{a} ] \). The structure of a block polymer can thus be characterized by assigning each block a monomer type, a contour length, and a pair of integer ids for the two vertices to which the block is attached. The length of each block is given by the ratio of the volume occupied by the block to the value of a monomer reference volume. Let \( N_{ma} \) denote the length of block \( m \) of polymer species \( a \).

Propagator Functions (Thread Model)

This section discusses the use of "propagator" functions to describe the statistical mechanics of individual polymers in an ideal gas reference system. For concreteness, this discussion uses a notation and analysis appropriate to the continuous thread model. The corresponding discussion for the bead model would be similar in many respects, but in not presented here.

Propagator Functions

For each block, we define two "propagator" functions, denoted generically by \( q( \textbf{r}, s) \). Each propagator is associated with one of the two directions in which the block may be traversed. Each propagator is said to originate at one of the two vertices to which the associated block is attached and terminate at the other. The contour variable parameter \( s \) is defined for each propagator \( q(\textbf{r},s) \) such that \( s = 0 \) at the vertex at which the propagator originates and \( s = N \) at the vertex at which the propagator terminates, where \( N \) is the contour length of the block. When we need to distinguish between the propagators associated with a single block, we will refer to them instead as \( q \) and \( q^{\dagger} \), though the choice of which is referred to as \( q \) and which \( q^{\dagger} \) is arbitrary.

For each vertex that is connected to \( M \) blocks, there are \( M \) propagators that originate at that vertex, which we refer to the "outgoing" propagators for that vertex, and \( M \) propagators that terminate at that vertex, which we refer to as "incoming" propagators. In what follows, we refer to a vertex with \( M \geq 2 \) attached blocks as an M-fold junction, and a vertex with only one attached block ( \( M = 1 \) as a chain end.

It is useful for some purposes to imagine a process in which we divide a block of length \( N \) into two blocks of length \( s \) and \( N - s \) by adding a "virtual" two-fold junction at some coordinate \( s \) within the block. This yields a two-fold vertex that is connected to two blocks of the same monomer type. The insertion or removal of this type of virtual vertex modifies the graph that we use to describe a polymer but does change our physical description of the underlying molecule.

Modified Diffusion Equation (MDE)

Each propagator \( q(\textbf{r}, s) \) associated with a block of monomer type \( i \) can be shown to obey a partial differential equation (PDE)

\[ \frac{\partial q}{\partial s} = -H_{i} q \quad\quad\quad\quad\quad (4) \]

in which \( H_{i} \) is a linear differential operator whose action on any function \( f({\bf r}) \) of position is defined to be

\[ H_{i} f({\bf r}) = - \frac{b_{i}^{2}}{6} \nabla^{2} f({\bf r}) + w_{i}(\textbf{r}) f({\bf r}) \quad\quad\quad\quad\quad (5) \]

in which \( b_{i} \) is the statistical segment length for monomers of type \( i \) , and \( w_{i}\) is the dimensionless SCF chemical potential field for such monomers. We refer to this PDE as the modified diffusion equation (MDE). Numerical solution of the MDE is the most computationally expensive operation in any SCFT program.

Initial Conditions :

The initial condition for propagators that originate at a chain end requires that

\[ q(\textbf{r},s=0) = 1 \quad\quad\quad\quad\quad (6) \]

for all \( \textbf{r} \) in the relevant spatial domain.

The initial value \( q(\textbf{r}, s=0) \) of an outgoing propagator that originates at an \( M \)-fold junction is given by a pointwise product of values of the \( M - 1 \) incoming propagators for that junction, excluding the incoming propagator associated with the same block as that of the outgoing propagator of interest.

Suppose we denote the outgoing propagators associated with the M blocks attached to an M-fold junction \( q_{m}({\bf r}, s) \), and denote the final or "tail" values of the M incoming propagators by \( q^{\dagger}_{a}({\bf r}) \), where \( m = 0, \ldots, M-1 \) is an integer identifer for the attached blocks. The initial condition for any propagator that originates at this vertex is then

\[ q_{m}({\bf r}, 0) = \prod_{n \neq m} q^{\dagger}_{n}({\bf r}) \quad\quad\quad\quad\quad (7) \]

where the product over \( n \) is taken over all \( [0, \ldots, M-1] \) except the value \( n = m \) corresponding to the block associated with the outgoing propagator of interest.

In the simple case of a linear polymer, for which every junction connects two blocks, the initial condition for the each outgoing propagator that originates at a junction is simply equal to the final value of the incoming propagator associated with the other block that is attached to that junction. Consider a linear polymer with \( B \) blocks in which blocks and vertices are indexed sequentially by their position relative to one end of the chain. This is the indexing scheme for blocks and vertices that is used internally by PSCF for polymers that are assigned a linear type parameter value within the parameter file, which is the default parameter value. Let \( N_{m} \) denote the length of block \( m \), which connects vertices \( m \) and \( m + 1 \). Let \( q_{m} \) denotes the propagator in block \( m \) that originates at vertex \( m \), and let \( q_{m}^{\dagger} \) denote the propagator in block \( m \) that originates at vertex \( m + 1 \). With this notation,

\[ q_{m+1}(\textbf{r},0) = q_{m}(\textbf{r}, N_{a}) \]

and

\[ q_{m}^{\dagger}(\textbf{r},0) = q_{m+1}^{\dagger}(\textbf{r}, N_{m+1}) \]

for \( m = 0, \ldots, B - 2 \).

As an example of a branched polymer, consider the case of a three armed star containing blocks with indices 0, 1 and 2 that are all connected at a central junction. Let \( N_{m} \) denote the length of block \( m \). Let \( q_{m}(\textbf{r},s) \) denote the propagator in block \( m \) that originates at the central junction, and let \( q_{m}^{\dagger}(\textbf{r},s) \) denote the propagator in block \( m \) that originates at a free end and terminates at the central junction. The initial condition for propagators that originate at chain ends requires that \( q_{m}^{\dagger}(\textbf{r},s=0) = 1 \) for all \( \textbf{r} \) and all \( m \). The initial condition for the outgoing propagator in block 0 that originates at the central vertex is then given by, for example, by

\[ q_{0}(\textbf{r}, s=0) = q_{1}^{\dagger}(\textbf{r}, N_1) q_{2}^{\dagger}(\textbf{r}, N_2) \quad. \quad\quad\quad\quad\quad (8) \]

Initial conditions for \( q_{1} \) and \( q_{2} \) are analogous.

Boundary Conditions :

In the pscf_rpc and pscf_rpg programs, the MDE for propagators in a periodic structure is solved within a single unit cell, subject to periodic boundary conditions.

In the pscf_r1d program, the MDE for each propagator \( q(x,s) \) is solved within a range of values of the single spatial coordinate \( x \), where \( x \) may represent either a Cartesian normal coordinate for a system with the geometry of a flat film or a radial coordinate for a system with cylindrical or spherical symmetry. In the case of a problem that is defined in cylindrical or spherical coordinates with a domain that includes \( x = 0 \), we must require that \( \partial q/\partial x = 0 \) at \( x = 0 \) in order to avoid introducing gradient discontinuities at the origin. In most foreseeable applications of this program, one or both of the limits of the computational domain is intended to represent a point that lies deep within homogeneous region, such as bulk region surrounding a micelle or a bulk phase far from an interface. In these cases, it is also appropriate to set \( \partial q/\partial x = 0 \) at these boundaries. In light of these considerations, the pscf_r1d program is designed to apply von Neumann boundary conditions requiring that \( \partial q/\partial x = 0 \) at both upper and lower limiting values of \( x \).

Monomer Probability Densities (Unnormalized)

Values of propagator functions that are obtained by solving the modified diffusion equation can be used to compute the probability of finding any point on a polymer chain within an ideal gas reference system at any at specified position within the relevant spatial domain: The probability per unit volume of finding a specified vertex of a polymer at a specific local \( {\bf r} \) can be shown to be proportional to the product of the incoming propagators for that vertex, at the the position \( {\bf r} \).

This relationship applies to an optional or "virtual" 2-fold vertex inserted at any point within any block of an acyclic branched polymer, as well as to vertices that are necessary to describe the polymer topology. Let \( \rho({\bf r}, s) \) denote the probability density per unit volume that a monomer or point with a contour coordinate \( s \) within a specified block of length \( N \) will be found within an infinitesimal volume centered at a position \( {\bf r} \). This quantity is given to within a constant of proportionality by

\[ \rho({\bf r}, s) \propto q({\bf r}, s) q^{\dagger}({\bf r}, N-s) \quad, \quad\quad\quad\quad\quad (9) \]

Here, \( q({\bf r}, s) \) and \( q^{\dagger}({\bf r}, N - s) \) are the two propagators associated with that block. These are also the two incoming propagators associated with a virtual vertex introduced at point \( s \) within the block. The two propagators in this product are evaluated at contour coordinates that correspond to the same point within the block, but are each evaluated at a value \( s \) or \( N - s \) that corresponds to the contour distance measured from the vertex at which that propagator originates. The more general expression for the probability density for the position of an M-fold vertex involves the product of the M incoming propagators, all evaluated at the same position \( {\bf r} \), and at contour coordinate values that correspond to the lengths of the associated blocks.

We show below that the constant of proportionality that relates the probability density for a vertex to the product of incoming propagators is the same for every vertex in a polymer, as well as for any possible virtual vertex (i.e., any monomer within any block of that polymer).

Theorems about Propagator Products

We may use the MDE and its associated initial and boundary conditions to prove the following series of theorems about products of incoming propagators associated with any vertex in a polymer.

Theorem A.1 : Suppose \( q({\bf r}, s) q^{\dagger}({\bf r},N-s) \) is the product of two propagators defined within a single block of length \( N \), defined such that \( q \) originates at the vertex with coordinate \( s = 0 \) and \( q^{\dagger} \) originates at the vertex with coordinate \( s = N \). The value of this product at \( s = 0 \) is equal to the product of all the incoming propagators at the vertex with coordinate \( s = 0 \), and the value of this product at \( s = N \) is equal to the product of all incoming propagators at the vertex with coordinate \( s = N \).

Proof : First consider the value at \( s = 0 \) for \( M > 1 \). The initial condition for \( q \) at \( s = 0 \) for an M-fold junction with \( M > 1 \) requires that \( q({\bf r}, s = 0) \) is equal to the product of the final values of incoming propagators associated with all other blocks that are attached to that vertex , excluding the incoming propagator associated with the block along which \( q \) and \( q^{\dagger} \) are defined. It follows immediately that the value of the product \( q({\bf r},s) q^{\dagger}({\bf r},N-s) \) at \( s = 0 \) is thus equal to the product of all incoming propagators at that vertex, including the incoming propagator \( q^{\dagger}({\bf r}, N-s)\) associated with the block of interest.

Next consider the case in which the vertex at \( s = 0 \) is a chain end, with \( M = 1 \). In this case, \( q(\textbf{r}, s) = 1 \), and so the product \( q q^{\dagger} \) simply yields the value of the single incoming propagagator \( q^{\dagger}(\textbf{r}, N) \). For \( M = 1 \), \( q^{\dagger}({\bf r}, N) \) is equal to the product of incoming propagators.

The corresponding statement about the value of \( q q^{\dagger} \) at \( s = N \) is obtained by completely analogous reasoning, with the roles of \( q \) and \( q^{\dagger} \) reversed.

Theorem A.2 : Let \( I(s) \) represent the spatial integral

\[ I(s) \equiv \int d\textbf{r} \; q (\textbf{r},s) q^{\dagger}(\textbf{r}, N-s) \quad\quad\quad\quad\quad (10) \]

of a product of two propagators that are both defined within a block of length \( N \), where \( s \) is the contour variable for a point within that block. If the propagators \( q \) and \( q^{\dagger} \) obey a modified diffusion equation within some domain, subject to periodic, Dirichlet, von Neumann or Robin boundary conditions, then the value of \( I(s) \) is independent of contour coordinate \( s \) for all \( s \in [0,N] \).

Proof : Note that

\begin{eqnarray*} \frac{dI(s)}{ds} & = & \frac{d}{ds} \int d\textbf{r} \; q (\textbf{r},s) q^{\dagger}(\textbf{r}, N - s) \\ & = & \int d\textbf{r} \; \left \{ \frac{\partial q (\textbf{r},s)}{\partial s} q^{\dagger}(\textbf{r}, N - s ) - q (\textbf{r},s) \frac{\partial q^{\dagger}(\textbf{r}, N-s)}{\partial s} \right \} \\ & = & -\int d\textbf{r} \; \left \{ [ \hat{H} q (\textbf{r},s) ] q^{\dagger}(\textbf{r}, N-s) - q (\textbf{r},s) [\hat{H} q^{\dagger}(\textbf{r}, N-s)] \right \} \quad. \quad\quad\quad\quad\quad (11) \end{eqnarray*}

We may then use the fact that the operator \( \hat{H} \) (like the analogous quantum mechanical Hamiltonian operator for a particle in a potential) can be shown to be a self-adjoint differential operator for any of the boundary conditions given in the theorem statement to show that

\[ \int d\textbf{r} \; [\hat{H} q (\textbf{r},s) ] q^{\dagger}(\textbf{r}, N-s) = \int d\textbf{r} \; q (\textbf{r},s) [\hat{H} q^{\dagger}(\textbf{r}, N-s) ] \quad, \quad\quad\quad\quad\quad (12) \]

implying a cancellation of the two terms in the integrand of the last expression for \( dI(s)/ds \). We thereby show that

\[ dI(s)/ds = 0 \quad\quad\quad\quad\quad (13) \]

for all \( s \in [0,N] \), implying that \( I(s) \) is independent of \( s \) within each block.

Theorem A.3 : The value of the spatial integral of the product of incoming propagators associated with a vertex of an acyclic branched polymer has the same value for every vertex in the polymer, including any virtual 2-fold vertex inserted into any block of the polymer.

Proof : This follows immediately from the combination of the preceding two theorems: Theorem A.2 shows that the value of the spatial integral \( I(s) \) of the product of incoming propagators associated with a virtual 2-fold vertex inserted into any block of a polymer is independent of the coordinate \( s \) within the block. Thereom Theorem A.1 then implies that the integral of the product of incoming propagators must also have the same value for any vertices that are directly connected by a block. Because any two distinct vertices in an acyclic branched polymer are connected by a unique path of one or more blocks, this implies that the value of this spatial integral must be the same for every vertex in any acyclic branched polymer. Theorem A.2 also implies that this applies to virtual 2-fold vertices that we insert at any point within any block.

Molecular Partition Function

Let \( Q_{a} \) denote a normalized single-chain partition function for a polymer molecule of species \( a \) within an ideal gas reference system that is subjected to a specified set of monomer potential fields. We define the value of \( Q_{a} \) to be equal to the spatial average (i.e., the integral over the entire spatial domain of the problem divided by the volume of this domain) of the product of the values of the incoming propagators evaluated at any vertex of the polymer. The statement of theorem A.3 implies that we should get the same value for \( Q_{a} \) by evaluating it using any vertex in a polymer of species \( a \). Different values for \( Q_{a} \) are, however, generally obtained for different species within a mixture.

A particularly compact expression for this quantity may be obtained by evaluating the incoming propagator at any chain end, for which the vertex is attached to a single block of length \( N \). In this case, the above definition yields

\[ Q_{a} = \frac{1}{V} \int \! d\textbf{r} \; q^{\dagger}(\textbf{r}, N) \quad\quad\quad\quad\quad (14) \]

where \( q^{\dagger}(\textbf{r}, N) \) denotes the final value of the single incoming propagator at that chain end. Here, the integral is taken over the entire spatial domain for the problem of interest, while \( V \) is the generalized volume of that domain. In the case of a periodic structure, the required spatial average may be evaluated by evaluating the integral over one crystallographic unit cell and then dividing by the generalized volume of that unit cell (i.e., the volume per unit cell for a 3D crystal, area per 2D unit cell for a 2D structure such as a hexagonal cylinder phase, or the length per unit cell in a 1D lamellar phase).

Another potentially useful expression for \( Q_{a} \) may be obtained by considering a virtual 2-fold vertex inserted at contour coordinate \( s \) within any block \( m \) of length \( N_{ma} \) of polymer species \( a \) and using the result of theorem A.3 to show that

\[ Q_{a} = \frac{1}{V} \int d\textbf{r} \; q (\textbf{r},s) q^{\dagger}(\textbf{r},N-s) \quad\quad\quad\quad\quad (15) \]

where \( N \) is the length of the chosen block, and where theorem A.3 guarantees that the value of the RHS of this equation is actually independent of the choice of values for \( s \) and block index \( m \).

Monomer Probability Densities (Normalized)

We can use the above definition of \( Q_{a} \) to write an explicit expression for the absolute probability density for the location of any specified monomer within an ideal gas reference system. Let \( \rho_{m a}({\bf r}, s) \) denote the probability density for the position \( {\bf r} \) of a monomer with contour coordinate \( s \) within block \( m \) of a single polymer of species \( a \) within a system that contains only a single polymer of this species, with no non-bonded pair interactions. By combining our previous proportionality, which gives this quantity to within a constant, with the requirement that integral of this probability density over the problem domain must equal unity, we find that

\[ \rho_{ma}({\bf r}, s) = \frac{1}{I_{ia}(s)} q({\bf r}, s) q^{\dagger}({\bf r}, N_{ia} - s) \quad, \quad\quad\quad\quad\quad (16) \]

in which \( q \) and \( q^{\dagger} \) are the two propagators associated with the block of interest, \( N_{ma} \) is the length of this block, and \( I_{ma}(s) \) is the spatial integral defined in the statement of theorem A.2, defined here for monomer with contour coordinate \( s \) within block \( m \) of polymer species \( a \). Using the expression given above to relate \( Q_{a} \) and \( I_{ma}(s) \), we find that

\[ \rho_{ma} ({\bf r}, s) = \frac{1}{V Q_{a}} q({\bf r}, s) q^{\dagger}({\bf r}, N-s) \quad\quad\quad\quad\quad (17) \]

for any choice of block index \( m \) and contour coordinate \( s \).

Block Volume Fractions

Consider a system that contains \( M_{a} \) chains of polymer species \( a \) within a total volume \( V \). The volume occupied by each such polymer is \( v N_{a} \), where \( N_{a} \) is the total length of polymer species \( a \), given by the sum of the length of all of the blocks of that polymer. Let \( \overline{\phi}_{a} \) denote the average overall volume fraction occupied by molecule species \( a \) within the mixture. This quantity is given by a ratio

\[ \overline{\phi}_{a} = \frac{M_{a} N_{a} v}{V} \quad\quad\quad\quad\quad (18) \]

where the numerator of the RHS is the total volume occupied by \( M_{a} \) such chains.

Let \( \phi_{ma}(\textbf{r}) \) denote the local volume fraction of monomers belonging to block \( m \) of polymer species \( a \). This quantity is related to the probability density \( \rho_{ia}({\bf r},s) \) defined above by

\[ \phi_{ia}({\bf r}) = v M_{a} \int\limits_{0}^{N_{ma}} \! ds \; \rho_{ma}({\bf r}, s) \quad, \quad\quad\quad\quad\quad (19) \]

where \( M_{a} \) is the total number of chains of species \( a \) and \( N_{ma} \) is the length of the relevant block. Rewriting \( v M_{a} \) in terms of \( \overline{\phi}_{a} \) then yields

\[ \phi_{ma}(\textbf{r}) = \frac{\overline{\phi}_{i}}{N_{a}Q_{a}} \int\limits_{0}^{N_{ia}} \! ds \; q(\textbf{r},s) q^{\dagger}(\textbf{r},s) \quad\quad\quad\quad\quad (20) \]

where \( N_{a} \) is the total contour length of all of the blocks of polymer species \( a \).

The total volume fraction \( \phi_{i}(\textbf{r}) \) for each monomer type \( i \) is simply the sum of volume fractions for all polymer blocks and all solvent species that have been assigned a monomer type index \( i \) .

Solvent species

Each solvent species \( a \) is associated with a specific monomer type \( i \) and a dimensionless "size" parameter. The size parameter for a solvent is a measure of volume closely analogous to the length parameter for a block in a block polymer, and is equal to the ratio of the volume per molecule occupied by the solvent to the monomer reference volume. In light of this analogy, we denote the "size" of solvent \( a\) here by \( N_{a} \).

In the single molecule problem for solvent species, the free energy penalty for a solvent molecule of monomer type \( i \) to be located at position \( \textbf{r} \) is given by \( k_{B}T N_{a} w_{i}(\textbf{r}) \) . This implies the existence of a solvent volume fraction field \( \phi_{a}(\textbf{r}) \propto \exp[-N_{a}w_{i}(\textbf{r})] \) .

We define a normalized molecular partition function \( Q_{a} \) for solvent species \( a \) that is given by an integral

\[ Q_{a} = \frac{1}{V} \int \! d\textbf{r} \; \exp (-N_{a}w_{i}(\textbf{r}) ) \quad\quad\quad\quad\quad (21) \]

for all \( a = P, \ldots, P + S - 1 \) . The local volume fraction \( \phi_{a}(\textbf{r}) \) for solvent species \( a \) is then given by a ratio

\[ \phi_{a}(\textbf{r}) = \frac{\overline{\phi}_{a}}{Q_{a}} \exp(-N_{a}w_{i}(\textbf{r})) \quad\quad\quad\quad\quad (22) \]

in which \( \overline{\phi}_{a} \) is the overall volume fraction of solvent species \( a \) within the mixture. Note that the prefactor in this expression is chosen to guarantee that the spatial average of \( \phi_{a}(\textbf{r}) \) (the integral divided by total volume) is given by the parameter \( \overline{\phi}_{a} \).

Open and closed ensembles

PSCF allows the user to choose either an open or closed statistical ensemble for each molecular species in the mixture, by allowing a user to enter a value for either the overall volume fraction for that species, denoted here by \( \overline{\phi}_{a} \), or a value for the chemical potential, denoted here by \( \mu_{a} \).

To use an open ensemble for a particular species in SCFT, one uses an open (i.e., grand-canonical) ensemble to treat the behavior of that species when considering the hypothetical ideal gas of non-interacting molecules subjected to a potential. Use of a grand-canonical ensemble to describe to a gas of molecules of species \( a \) yields an overall concentration for that species and a corresponding overall volume fraction \( \overline{\phi}_{a} \) that are both proportional to the product \( e^{\mu_{a}/k_{B} T} Q_{a} \). The value of the constants of proportionality in the expressions depends upon arbitrary choices of convention for normalizing volume used to relate the configurational integral for a single chain to a dimensionless partition function and a choice of reference state used to define the chemical potential. In the equations used in PSCF, we set

\[ \overline{\phi}_{a} = e^{\mu_{a}/k_{B} T} Q_{a} \quad, \quad\quad\quad\quad\quad (23) \]

as a matter of convention.

Calculations of the local volume fractions for monomers within a specific block of a block copolymer and for the local volume fraction of a solvent species are thus performed for molecular species that are treated in an open ensemble, by simply replacing the parameter \( \overline{\phi}_{a} \) by the above expression in all expressions that involve \( \overline{\phi}_{a} \).

The value of the chemical potential is computed for any species that is treated in a closed ensemble (i.e., any species for which a volume fraction is specified in the parameter file) by computing

\[ \frac{\mu_{a}}{k_{B}T } = \ln \left ( \overline{\phi}_{a} / Q_{a} \right ) \quad, \quad\quad\quad\quad\quad (24) \]

after computing \( Q_{a} \).

Values of species chemical potentials in both input and output files used by PSCF, which are denoted indicated the label "mu", are given in thermal energy units, and thus are correspond to values of the ratio \( \mu_{a}/k_{B}T \).

Overview: SCFT Working equations

The above discussion provide a complete set of working equations for SCFT of an incompressible liquid in the form implemented in PSCF, for calculations in a fixed spatial domain. We simplify the discussion by restricting ourselves here to calculation that are carried out in a fixed one-dimensional or periodic spatial domain. Extension to SCFT calculations in a periodic unit cell with flexible parameters, as performed by pscf_rpc or pscf_rpg programs, would require an additional set of working equations to impose a requirement that the free energy density be minimized with respect to variation of the unit cell parameters. The working equations for a PSCF SCFT calculation in a fixed spatial domain are:

  • The modified diffusion equation [Eqs. (4) and (5)]
  • A definition of \( Q_{a} \) for each species [Eq. (14) for polymers and Eq. (21) for solvents]
  • The relationship between \( \overline{\phi}_{a} \) and \( \mu_{a} \) [Eq. (23) or (24)]
  • Expressions for block and solvent monomer volume fractions [Eq. (20) for a polymer block and (22) for a solvent]
  • Self-consistent field condition [Eq. (3)]
  • Incompressibility constraint [Eq. (2)]
  • Expression for non-dimensional Helmholtz free energy per monomer, \( f \), given here.
  • Expression for non-dimensional pressure \( p \), or the associated non-dimensional grand-canonical free energy, given here.

The key outputs from solution of this set of equations are:

  • A converged monomer chemical potential field \( w_{i}({\bf r}) \) ("w field") for each monomer type \( i = 0, \ldots, C-1 \)
  • A converged monomer concentration field ("c field") \( \phi_{i}({\bf r}) \) for each monomer type \( i \)
  • A chemical potential \( \mu_{a} \) or overall volume fraction \( \overline{\phi}_{a} \) for each polymer and solvent species \( a \) (depending on whether \( \overline{\phi}_{a} \) or \( \mu_{a} \) was provided as an input parameter for that species)
  • Values for non-dimensionalized Helmholtz free energy \( f \) and pressure \( p \).

The required inputs to such an SCFT calculation are:

  • A statistical segment length for each monomer type
  • A description of each block polymer type as a list of block lengths and vertex indices for attached vertices
  • A size (ratio of molecular volume to monomer reference volume) for each solvent species
  • Values for all elements of the symmetric matrix of Flory-Huggins interaction parameters
  • A description of the spatial domain and boundary conditions

Monomer reference volume

It is straightforward to confirm that the monomer reference volume \( v \) does not appear as an input parameter in any of the final working equations enumerated above. This parameter is thus not a required input parameter for an SCFT calculation.

PSCF allows the user to optionally input a value for \( v \) in the parameter file (labelled as "vMonomer"), but this value is not used in the solution of SCFT equations. The option of entering a value is provided because:

  • A value for \( v \) is required as an input to field theoretic simulations that can be performed by pscf_rpc and pscf_rpg.
  • A value for \( v \) is required to compute some physical quantities that can be inferred from solution of a SCFT problem.

The role of the monomer volume in PS-FTS simulation is discussed in the next manual section. We discuss the use of monomer volume in the interpretation of SCFT results below.

A value for \( v \) is required in the analysis of SCFT results to compute some physical properties that require knowledge of the number of monomers or molecules that can pack into a region of space. In SCFT treatments of periodic structures formed by a block polymer material, such properties include the number of molecules per unit cell and the total free energy per unit cell. For calculations that can be performed by pscf_1d code, such properties include, for example, the aggregation number and total excess free energy of a spherical micelle, the interfacial tension of an interface, and the excess concentration per area (adsorbed molecules per area) of a species that absorbs to an interface. The pscf_r1d program provides specialized commands that can compute several of these properties of micelles and interfaces, but that require a value for \( v \) to be provided in the parameter file.
