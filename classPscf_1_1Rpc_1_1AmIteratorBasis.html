Detailed Description

template<int D>
class Pscf::Rpc::AmIteratorBasis< D >

Anderson mixing iterator with imposed space-group symmetry).

Specializations of this template with D=1, 2, and 3 are derived from specializations of the base class template Rp::AmIteratorBasis, and inherit their public interface and almost all of their source code from this base class.
