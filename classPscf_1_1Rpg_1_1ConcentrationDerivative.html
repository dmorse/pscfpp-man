Detailed Description

template<int D>
class Pscf::Rpg::ConcentrationDerivative< D >

Evaluate and average the derivative of H with respect to chi.

Specializations of this template with D=1, 2, and 3 are derived from specializations of base class template Rp::ConcentrationDerivative, and inherit their public interface and almost all of their source code from this base class.
