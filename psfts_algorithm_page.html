The pages linked below discuss several different types of algorithm that are used to perform and analyze PS-FTS calculations, and that are not also used for SCFT calculations. We focus here on explaining the different types of algorithm that are required, and on listing the available choices among sets of algorithms of each type (e.g., different available Brownian dynamics step algorithms). Links to user documentation for specific algorithms are available via pages linked below that discuss particular types of algorithm. A subsequent page is devoted to a description of the format of the parameter file for a PS-FTS calculation, including a description of locations of file sections that specify choices for each type of algorithm.
