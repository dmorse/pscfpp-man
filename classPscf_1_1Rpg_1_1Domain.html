Detailed Description

template<int D>
class Pscf::Rpg::Domain< D >

Spatial domain for a periodic structure with real fields, on a GPU.

Specializations of this template with D=1, 2, and 3 are derived from corresponding specializations of base class template Rp::Domain, and inherit their public interface and all of their source code from this base class.
