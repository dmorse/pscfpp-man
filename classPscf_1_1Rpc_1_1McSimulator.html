Detailed Description

template<int D>
class Pscf::Rpc::McSimulator< D >

Monte Carlo simulator for PS-FTS.

Specializations of this template with D=1, 2, and 3 are derived from specializations of the base class template Rp::McSimulator , and inherit their public interface and almost all of their source code from this base class. See the documentation of this base class template for details.
