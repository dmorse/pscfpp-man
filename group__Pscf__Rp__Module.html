Detailed Description

Class templates for use SCFT and PS-FTS with real fields.

The Pscf::Rp namespace contains class templates that are designed to be used in both the Pscf::Rpc and Pscf::Rpg namespaces, for SCFT and PS-FTS calculations with real-valued periodic fields. Specializations of class templates defined in the Pscf::Pc namespace are used as a base classes for specializations of corresponding class templates that are defined in the Pscf::Rpc and Pscf::Rpg namespaces.
